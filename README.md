## About

I learn by shipping. My work spans full-stack web applications, AI/LLM tooling, and automation — with a focus on systems that are safe by design, such as agents that require explicit human approval before taking action.

I am currently pursuing a **B.Tech in Computer Science Engineering** and building projects that turn ideas into working software.

- Currently building **approval-gated AI agents** and full-stack tools
- Learning **system design, TypeScript, and LLM orchestration**
- Interested in **developer tools, AI safety, and practical automation**
